개인정보처리방침

최종 업데이트: 2026년 3월 14일 v1.0

생일MBTI(이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 서비스가 어떤 정보를 수집하고, 어떻게 이용·보호하는지 설명합니다.

1. 수집하는 정보

1-1. 사용자가 직접 입력하는 정보

  • 생년월일 (6자리 숫자) — 사주 기질 분석에 사용
  • 성별 — 기질 성향 분석에 사용
  • 성격 테스트 응답 (선택사항) — 결과 보정에 사용
  • Gemini API 키 (선택사항) — AI 심화 분석 기능 이용 시 사용자가 직접 입력
⚠️ 생년월일·성별·테스트 응답은 서버에 전송되거나 저장되지 않습니다. 모든 분석은 사용자의 기기(브라우저) 내에서만 처리됩니다.

1-2. 자동으로 수집되는 정보

  • 언어 설정 — 브라우저 로컬 스토리지에 저장 (서버 전송 없음)
  • Gemini API 키 — 입력 시 브라우저 로컬 스토리지에만 저장 (서버 전송 없음, 사용자가 언제든 삭제 가능)
  • 접속 로그 — Firebase Hosting 서버가 표준 접속 로그(IP, 접속 시간, 요청 URL)를 자동 수집할 수 있습니다. 이는 Google Firebase의 정책에 따릅니다.

2. 제3자 서비스

Google Gemini API (선택사항)

AI 심화 분석 기능을 사용하는 경우, 사용자가 입력한 생년월일·성별 정보가 Google의 Gemini API로 전송됩니다. 이 기능은 사용자가 직접 API 키를 입력했을 때만 활성화됩니다.

Google의 데이터 처리 방식: Google 개인정보처리방침

Firebase Hosting (Google)

서비스는 Google Firebase Hosting을 통해 제공됩니다. Firebase는 서비스 운영에 필요한 기본 접속 로그를 수집할 수 있습니다.

Firebase 정책: Firebase 개인정보 및 보안

Google AdSense

서비스는 Google AdSense를 통해 광고를 게재합니다. Google AdSense는 사용자의 관심사에 맞는 광고를 표시하기 위해 쿠키를 사용할 수 있습니다. 사용자는 Google 광고 설정에서 맞춤 광고를 끌 수 있습니다.

Google의 광고 정책: 광고 정보

Google Fonts

가독성을 위해 Google Fonts를 사용합니다. 폰트 로드 시 Google 서버에 요청이 발생할 수 있습니다.

3. 쿠키 및 로컬 스토리지

  • 로컬 스토리지 (언어 설정, API 키) — 서비스가 직접 저장하며 외부로 전송하지 않습니다. 브라우저 설정에서 삭제할 수 있습니다.
  • 광고 쿠키 (Google AdSense) — Google이 설정하는 쿠키로, 광고 개인화에 사용됩니다. 브라우저 설정 또는 Google 광고 설정에서 관리할 수 있습니다.

4. 정보의 이용 목적

  • 생일 기반 MBTI 기질 분석 결과 제공
  • 다국어 서비스 지원 (언어 설정 유지)
  • AI 심화 분석 기능 제공 (API 키 입력 시에만)
  • 서비스 안정성 유지 및 오류 대응

5. 정보 보유 및 삭제

서비스가 직접 저장하는 정보(언어 설정, API 키)는 사용자의 기기 로컬 스토리지에만 존재하며, 브라우저 설정에서 언제든 삭제할 수 있습니다. 서버에는 어떠한 개인정보도 저장하지 않습니다.

6. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보를 고의로 수집하지 않으며, 발견 시 즉시 삭제 조치합니다.

7. 이용자의 권리

  • 브라우저 설정을 통해 로컬 스토리지 데이터를 언제든 삭제할 수 있습니다.
  • 광고 쿠키 설정은 브라우저 또는 Google 광고 설정에서 변경할 수 있습니다.
  • Gemini AI 기능은 API 키를 입력하지 않으면 사용되지 않습니다.

8. 방침 변경 안내

본 개인정보처리방침이 변경되는 경우 이 페이지에 변경 일자와 함께 공지됩니다. 지속적인 서비스 이용은 변경된 방침에 동의하는 것으로 간주됩니다.
