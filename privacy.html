개인정보처리방침

최종 업데이트: 2026년 3월 14일 v1.0

생일MBTI(이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 서비스가 어떤 정보를 수집하고, 어떻게 이용·보호하는지 설명합니다.

1. 수집하는 정보

직접 입력 정보

  • 생년월일 (6자리) — 사주 기질 분석에 사용
  • 성별 — 기질 성향 분석에 사용
  • 성격 테스트 응답 (선택) — 결과 보정에 사용
  • Gemini API 키 (선택) — AI 심화 분석 시 사용자가 직접 입력
⚠️ 생년월일·성별·테스트 응답은 서버에 전송되거나 저장되지 않습니다. 모든 분석은 사용자 기기 내에서만 처리됩니다.

자동 수집 정보

  • 언어 설정 — 브라우저 로컬 스토리지에만 저장
  • Gemini API 키 — 로컬 스토리지에만 저장, 사용자가 언제든 삭제 가능
  • 접속 로그 — Firebase Hosting 서버가 표준 로그(IP, 접속 시간) 수집 가능

2. 제3자 서비스

Google Gemini API (선택)

AI 심화 분석 사용 시, 생년월일·성별이 Google Gemini API로 전송됩니다. API 키 입력 시에만 활성화됩니다. Google 개인정보처리방침

Firebase Hosting

서비스는 Google Firebase Hosting을 통해 제공됩니다. Firebase 개인정보 정책

Google AdSense

서비스는 Google AdSense 광고를 게재합니다. AdSense는 맞춤 광고를 위해 쿠키를 사용할 수 있습니다. 광고 설정에서 관리 가능합니다. Google 광고 정책

Google Fonts

가독성을 위해 Google Fonts를 사용합니다.

3. 쿠키 및 로컬 스토리지

  • 로컬 스토리지 — 언어·API 키 저장, 외부 전송 없음, 브라우저에서 삭제 가능
  • 광고 쿠키 (Google AdSense) — Google이 설정, Google 광고 설정에서 관리

4. 정보 이용 목적

  • 생일 기반 MBTI 기질 분석 결과 제공
  • 다국어 서비스 지원
  • AI 심화 분석 (API 키 입력 시)
  • 서비스 안정성 유지

5. 정보 보유 및 삭제

서비스가 직접 저장하는 정보는 로컬 스토리지에만 존재하며 브라우저 설정에서 언제든 삭제할 수 있습니다. 서버에는 개인정보를 저장하지 않습니다.

6. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 방침 변경 안내

방침 변경 시 이 페이지에 변경 일자와 함께 공지됩니다.

AI詳細分析機能を使用する場合、生年月日・性別がGoogle Gemini APIに送信されます。APIキーを入力した場合のみ有効化されます。Googleプライバシーポリシー

本サービスはGoogle Firebase Hostingを通じて提供されます。Firebaseプライバシーポリシー

本サービスはGoogle AdSenseを通じて広告を表示します。AdSenseはパーソナライズ広告のためにCookieを使用する場合があります。広告設定で管理できます。Google広告ポリシー

Google Fonts

読みやすさのためにGoogle Fontsを使用しています。

3. CookieおよびローカルストレージStorage

  • ローカルストレージ — 言語設定・APIキーを保存。外部送信なし。ブラウザから削除可能
  • 広告Cookie（Google AdSense） — Googleが設定。Google広告設定で管理可能

4. 情報の利用目的

  • 生年月日に基づくMBTI気質分析結果の提供
  • 多言語サービスの提供
  • AI詳細分析（APIキー入力時）

5. 情報の保存と削除

本サービスが直接保存する情報はローカルストレージにのみ存在し、ブラウザ設定からいつでも削除できます。サーバーには個人情報を保存しません。

6. 子どものプライバシー

7. ポリシーの変更
